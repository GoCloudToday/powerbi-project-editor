# Reports (PBIR)

Visuals, formatting, cards and matrices, bookmarks, cloned pages, rebinding and renames, report-level measures. Rows moved verbatim from the v1 SKILL.md quick reference in v2.0.0; `§` references point to [reference.md](../reference.md). Where a row disagrees with the core, the row wins.

When the `powerbi-report-author` CLI is installed, use it for visual roles, formatting objects and enum values (`catalog describe`, `formatting describe-object`), value encoding (`expr encode`), validation (`validate`), new projects (`scaffold`) and transport (`pack`, `unpack`). The rows about generating or hand-writing PBIR stay as the fallback and as the checks the CLI does not do: selector and binding fidelity (Iron Rule 8), bookmark state, byte identity.

| Situation | Rule |
|---|---|
| Styling a hand-generated report | The property dictionary is the report theme JSON schema (`microsoft/powerbi-desktop-samples`, `reportThemeSchema-<latest>.json`): a visual resolves to `definitions/visual-<type>` = `commonCards` + its own cards, every property with its enum. A wrong key AND a wrong enum case (`right` vs `Right`) are both silent no-ops. Gates check bindings, not readability: render every page with the export API, and compute the series colours' distances (two brand dark blues read as one; a green next to an orange collapses for red-green colour blindness). reference.md §2026-09-21, §2026-11-23 round 27. |
| Hand-built chart: series colour, constant line, dynamic title | One-measure column chart: `dataPoint` `fill` WITHOUT a selector (a `metadata` selector is ignored silently; sample pixels). Constant line from a measure: `y1AxisReferenceLine` `value: {expr: {Measure}}` + `selector: {id: "1"}`. Title and subtitle from measures render, but a visual-level filter applies to them too: blank the bar measure for the blank member (`ISINSCOPE` + `SELECTEDVALUE`) instead of filtering it. reference.md §2026-11-12 round 22. |
| Card visual looks wrong | The base theme draws a per-card border and fill: turn off `outline` (selector id `default`) and `fillCustom`, not just the container `background`. It needs ~50 px height for value+label, or the label renders OUTSIDE the container and is clipped. An empty-string label measure falls back to the FIELD NAME. reference.md §2026-09-21. |
| Table/matrix cell colours (conditional formatting) | A per cell rule needs `selector: {data: [{dataViewWildcard: {matchingOption: 1}}], metadata: "Table.Field"}` — without the `data` wildcard it addresses the whole COLUMN and the colour measure is evaluated once (no cell changes, or every cell gets one colour). `matchingOption` 1 = values only, 0 = values AND totals (use 0 for a stepped matrix's region/cluster rows, which are subtotal rows). With the wildcard, banded rows and conditional colours coexist. The row style itself is FOUR properties (`backColorPrimary`/`Secondary`, `fontColorPrimary`/`Secondary`); a plain `fontColor` colours no rows. Verify by sampling pixels. reference.md §2026-09-21 round 2. |
| Table/matrix draws a horizontal scrollbar | Column widths that sum to the visual width overflow (the container's padding is outside the sum) — leave ~30 px and assert the sum in the generator. The matrix also renders its grand-total row when every measure is blank; `subTotals.rowSubtotals=false` removes it but can blank parent rows in the stepped layout. |
| Matrix shows each row level on its own line (a staircase) although stepped layout is off | Set `objects.general[0].properties.layout = 'Tabular'` (`Compact` / `Outline` / `Tabular`); stepped off alone is Outline. With a column field the period names become header cells over their value columns. reference.md §2026-10-23 round 4. |
| Matrix header labels will not centre, or a numeric row field will not right align | `columnHeaders.alignment` moves the column field's headers (names spanning their value columns) and the value captions; `titleAlignment` the captions over the row fields. Row headers have no per field alignment (`Auto` and a `columnFormatting` selector leave a number left): keep such a figure a value or accept it. reference.md §2026-10-23 round 6. |
| A table shows only one column and every dimension member, no measures, no error | A projection with `active: true` on a `tableEx` hides every projection without the flag. `active` belongs only to drill roles (matrix rows and columns, a chart axis, slicers). reference.md §2026-10-23 round 4. |
| Button slicer buttons render without text, or show an extra "--" button | Short box: `padding` Custom with 0 margins and `value.verticalAlignment: 'middle'`; states via selectors `selection:selected` / `interaction:hover` (bold on the pick can cut its label). "--" is the blank member of a dual options table on the one side of a DirectQuery relationship: a visual-level "is not blank" filter on its key. reference.md §2026-10-23 round 4. |
| Cloning a report page onto a parallel model | Rebind `queryRef` + Entity/Property nodes; KEEP `nativeQueryRef` — custom-visual embedded state (Zebra BI) keys on it, so old aliases preserve formatting without touching opaque blobs. Slicer selections live in `objects.general[].properties.filter` literals, NOT filterConfig. Regenerate page/visual/filter names (folder name must equal visual.json `name`). Verify: TOM field-inventory cross-check — every bound (Entity, Property) and queryRef prefix must resolve; zero legacy entities remain. |
| "Copy this page but on a different date column" | Don't rebind visuals. Inactive relationship `Fact[X]→Date[Date]` (+ `joinOnDateBehavior: datePartOnly` if X has a time part) + a two-item calc group (`SELECTEDMEASURE()` / `CALCULATE(SELECTEDMEASURE(), USERELATIONSHIP(...))`, explicit `precedence:`) + ONE hidden page-level filter on the group column in the clone. Composes with time-intelligence groups; no M change so no refresh. Sweep the page's measure queryRefs against the model first — cloned pages propagate phantom bindings. reference.md §2026-08-28 round 2. |
| Date-hierarchy field on a copied page | The `.Variation.Date Hierarchy.Year` binding can be swapped to a plain int column by replacing the whole HierarchyLevel node with a Column node. But the slicer's SELECTION filter also carries the LocalDateTable entity in `From` + `Annotations.filterExpressionMetadata` (incl. a display `valueMap`) — an entity-collection audit catches what eyeballs miss. |
| "Filter out X from the report" | Default to a visible report-level `filterConfig` filter (hand-authorable; shape in reference.md §2026-07-21), not a hard exclusion inside a calc table — and never both: a hard filter under a pane card makes the toggle lie. Verify parity engine-side (`CALCULATE` emulation vs old counts). |
| Retargeting a field parameter | THREE attachment points: calc-table NAMEOF, the bound visual's Category projection, AND the parameter slicer's stored selection literals (`'''T''[C]'` appears twice in its visual.json). A stale literal renders ONE unsegmented bar, zero errors. Grep the report for the old NAMEOF after any retarget. |
| Dynamic multi-line or mixed-color text | Native cards can't: no word wrap, `UNICHAR(10)` renders as a space, one fontColor per value, multi-tile stacks show only tile 1 plus an overflow pill. Use the HTML Content (lite) custom visual (queryState role key `content`) with a measure returning styled HTML spans; park replaced native cards with visualContainer `"isHidden": true`. Recipes: reference.md §2026-07-22 rounds 2–5. |
| Nudging text inside a hand-built card, or one line of button text sits low | Use `visualContainerObjects.padding.top` (`…D` literal) — measured reliable. `cardCalloutArea.paddingTop` moved text on a Desktop-authored card but NOT on a hand-cloned one; card heights below ~24px render nothing. A new card's `layout.alignment` is VERTICAL: Desktop writes `'top'` (the theme schema's horizontal enum is wrong; its `center` left the content low); `'top'` plus the card's `padding` (Custom, four `0L` margins) starts the content at the box top, so the box's y places the label. A new card with its label HIDDEN sits the value on its bottom edge and cuts the descenders (10 pt in 32 px); for one line of measure text use an `actionButton` with no `visualLink` instead: `text` takes the measure plus `horizontalAlignment`, `verticalAlignment: 'middle'` and `topMargin` / `bottomMargin` `0L` (the default margins left a line 2 to 3 px low in an 18 px box). reference.md §2026-09-26, §2026-10-23 round 8. |
| Hand-authoring a thin report's `byConnection` | Desktop and the service parse the connectionString DIFFERENTLY: the service binds by `semanticmodelid=` alone (bogus Data Source still renders online); Desktop dials `Data Source=` for real, and **My Workspace has no XMLA path** (`powerbi://...myorg/My workspace` → "workspace is not found"). Universal shape = the one Desktop writes: `Data Source=pbiazure://api.powerbi.com;initial catalog=<datasetGuid>;identity provider="https://login.microsoftonline.com/common, https://analysis.windows.net/powerbi/api, 7f67af8a-fedc-4b08-8b4e-37c4d127b6cf";integrated security=ClaimsToken;semanticmodelid=<datasetGuid>` (+optional `modelid=<n>`). reference.md §2026-08-07 round 5. |
| Report stuck on "Loading your report..." after a trim | Binding/pages endpoints healthy but render spins forever → grep BOOKMARKS for dropped table names: explorationState still snapshots deleted visuals filtered on deleted tables. Prune `explorationState.sections.<page>.visualContainers.<name>` for every visual no longer on the page. reference.md §2026-08-07 round 5. |
| Generating PBIR visuals from PowerShell | Members of `objects`/`visualContainerObjects` must be ARRAYS — a helper function returning a single-element array gets unwrapped on return (`"title": [{…}]` → `"title": {…}`) and Desktop refuses the report ("Property /visual/visualContainerObjects/title … was not provided as the correct type", one line per visual). Return ONE object, wrap at the call site with `@(...)`, and shape-audit every member for IList. The same unwrap on a query role's `projections` (a one-field slicer) names NO property at all: "Failed to load the report", activity id only; audit every role's `projections` for IList too (reference.md §2026-09-26). Also: a validator step that COPIES resources must normalize (BOM-strip) at copy time, or each rerun reintroduces the bug it checks for. reference.md §2026-08-31 round 2. |
| Copying a static resource (theme) into a PBIR project | The file must be UTF-8 WITHOUT BOM — Desktop refuses the whole project open ("Only text with UTF8 encoding without BOM (byte order marks) is supported. Detected BOM: 'UTF-8'") and falls back to an "Untitled" window with an EMPTY workspace DB, so a headless cycle sees a catalog with 0 TMSCHEMA tables forever (dialog-blocked, not slow — screenshot the desktop and read the dialog instead of polling blind). `Copy-Item` preserves the source's BOM: strip EF BB BF and BOM-sweep the project. TMSCHEMA DMVs also need `Initial Catalog` (discover via DBSCHEMA_CATALOGS) or they return 0 rows without error. reference.md §2026-08-31. |
| Report-level (extension) measures on a read-only dataset | Every reference to one — projections, filter fields AND `From` entries, sorts, bookmarks, title bindings — carries `Schema: "extension"`; `queryRef` stays `Host.Measure`; measure-to-measure `references.measures[]` need `schema: "extension"` too. Otherwise "Missing_References" / "QueryDefinition Select is missing" on every measure-only visual while an offline audit stays green. Validate the file with `Test-Json` against the reportExtension schema (self-contained). reference.md §2026-09-09 round 2. |
| Two views on one page switched by bookmarks | The bookmark does NOT set the page's own state: every visual the bookmark hides must ALSO carry `"isHidden": true` in its visual.json, or the saved page opens with both views stacked. reference.md 2026-09-20. |
| Generating PBIR from PowerShell (data side) | An array literal written one element per line UNROLLS nested arrays (four scalars instead of two arrays); a parameter named `$view` shadows a `$View` hashtable (variable names are case insensitive). A synced folder also holds `definition\pages` after Desktop closes - clear the CHILDREN with retries, never the folder. reference.md 2026-09-20. |
| A number renders as `42.5,,MM` | A scaling format string (`#,##0.0,,"M"`) collided with the visual's own display units: the commas printed literally and the card appended its own M. Let one side scale - `labelDisplayUnits` on the visual, plain `#,##0` on the measure. |
| Hand-written bookmarks / page visibility | `display.mode` accepts only `"hidden"` (visible = omit the node). Same for PAGES: `page.json` `visibility` is `HiddenInViewMode` or ABSENT — writing `"Visible"` makes Desktop refuse the WHOLE report ("Failed to load the report", no detail); unhide by deleting the key. Desktop's view bookmarks are display-only (`suppressData`) — a copy meant to carry a slicer value must be stripped of all captured data and un-suppressed, then given the single slicer entry. |
| Selector that must show the same state from several places (n × k) | Bookmark navigators light click history; use action buttons with measure-bound fill/font over a hidden surrogate slicer, one bookmark per (view, state); encode extra views (e.g. "profile") as extra slicer values. |
| Rebinding measures in a report that has been renamed around before (sharpens Rule 8) | A Desktop-saved projection's ACTUAL `queryRef` can be a LEGACY ALIAS ≠ `Table.Measure`, and the conditional-format `selector.metadata` keys on the alias — live formatting, not a leftover (2 of 32 mapped projections here). So a guard `if queryRef != f"{t}.{m}": raise` FIRES on real data: instead rewrite to the canonical NEW form and map BOTH the canonical old and the stale old, so a selector keyed on either follows. A "stale selector" audit must compare against the visual's ACTUAL queryRef set, never a reconstructed `Table.Measure` — reconstruction reports live formatting as dead (genuinely stale here: 0 across 211 visuals / 34 selectors). reference.md §2026-09-07. |
| Renaming a measure or a label across a report | Binding-field scans (`Entity`/`Property`/`queryRef`/`selector.metadata`) exempt display text BY DESIGN, so a custom visual's title — a DAX literal in `objects.<name>Settings` `Literal.Value` — passes every one of them while the chart still shows the retired wording. Add a SEPARATE display-text gate over `displayName` + `Literal.Value` + textbox `textRuns[].value` (4,736 strings here: 5 findings on the un-renamed source, 0 after; the repair was one line in one of 236 files). Keep `nativeQueryRef` exempt — custom visuals key per-column state on it. reference.md §2026-09-07. |
| Porting a report's custom visuals | AppSource visuals travel as IDS in `report.json` `publicCustomVisuals` — nothing to import, Desktop downloads each on first open. Copy the list; an id no visual uses can be dropped (1 of 3 here, after which the rebuilt `report.json` differed from its source by exactly one line — independent evidence the double serialiser reproduces Desktop's bytes on the project's largest file). Hygiene both directions: every type in use registered, every registered id in use. reference.md §2026-09-07. |
| Field map moves a field to another table (report transport) | Set each filter's `From` entity from the table of the alias-sourced fields in its `Where`, not from the entity default — otherwise the condition reads a property the aliased table lacks (1 visual + 6 bookmarks here). The gate must resolve `From` aliases and `selector.metadata` too: a direct-`Entity`-only self-audit passed 2,305 / 0 while an independent checker found 25. reference.md §2026-09-15 round 4. |
| One table row can't be picked, or one name in a link column isn't underlined | The table merged source rows whose SHOWN columns are all equal (duplicate records, two accounts of one name); `HASONEVALUE(Id)` fails on the merged row, so URL measures blank and a translytical band silently falls back to its nothing-selected meaning (e.g. a save for everyone). Make the shown name unique in the source per visual scope, number IN FRONT (`(2) Name`; a suffix hides behind the ellipsis). Audit `GROUP BY scope, Name HAVING COUNT(*) > 1` = 0. reference.md §2026-10-06. |
| Column widths and alignment for a report people use in the service | Measure from SERVICE screenshots (canvas clip over CDP, scale 2): the service draws 9 pt wider than Desktop. A table that never scrolls fills to width - 4; one that scrolls keeps a 14 px lane. Matrix total colours = rowTotal; the row headers' own header = columnHeaders.titleAlignment; Reset to default before a screenshot of what a new viewer sees. reference.md §2026-10-30 round 16. |
