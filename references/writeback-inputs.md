# Writeback and input pages

Data-function buttons, input slicers and pages where saving depends on rights. Rows moved verbatim from the v1 SKILL.md quick reference in v2.0.0; `§` references point to [reference.md](../reference.md). Where a row disagrees with the core, the row wins.

Not covered by the core.

| Situation | Rule |
|---|---|
| Translytical input slicer / data-function button | Both fully hand-authorable. Input box = `textSlicer` with NO projections. Button = `actionButton` + `visualLink` `{show, type 'DataFunction', dataFunction{...}}` — the `dataFunction` node (structured, not `{expr}`) carries itemId/workspaceId literals + full parameter bindings (column params wrapped in `Aggregation` Function 3; slicer params reference the input slicer's visual NAME). itemId/workspaceId are environment-bound — rewrite on cross-workspace promotion. Button slicers and list slicers bind the same way (SlicerParameter by visual name); a list slicer becomes a dropdown with `objects.data dropdownMode true`; a selection hidden by another slicer is still SENT, so the function validates parent/child pairs. A date picker (or any older slicer) feeds a parameter only through a measure that reads its pick (not cleared after a save); use the After style (`slider.show false`, `general.responsive false`): the Date Picker style opens its calendar on the last day of the column, reference.md §2026-10-30 round 17; a list slicer of months binds directly, reference.md §2026-10-28 round 11. Full shape: reference.md §2026-08-04 round 3, §2026-10-23 round 3. |
| Input box must look unusable (no row picked, no rights) | Put a no-action `actionButton` tile under the `textSlicer` (same rect, one z lower, fill bound to a measure: grey or white) and set the box's `inputTextBox.backShow` false; tile every box on the band so they match. The slicer on top keeps the clicks. Still refuse the value on save. reference.md §2026-10-23. |
| "Global" users see everything but every save is refused | Read access (a role without filters) and write access (a user list the save procedure checks) live in two places. Make global ONE entry kept with the write rights that also lifts the dynamic-RLS filters, name the read role after it, give members both, and gate per person. App viewers also need Execute on the functions item. reference.md §2026-10-12. |
| Button that must look disabled | Bind `fill.fillColor` to a MEASURE returning two hex strings; `selector.id = 'disabled'` never fires for a data-function button. Verify text/colour states with a DAX probe (`UNION` of `CALCULATETABLE(ROW(…), <one filter per state>)`), not by eye. |
